Privacidad de tus consultas

Cuando envías el formulario, Fernely Dev recibe tu nombre, correo, servicio de interés y mensaje. El teléfono es opcional. Si visitas la web desde una campaña, también podemos guardar el nombre de esa campaña para saber cómo llegaron las consultas.

Usamos esos datos únicamente para responderte y conversar sobre el proyecto. Se guardan en el servidor privado de la cuenta de hosting y solo Fernely Dev puede acceder. No incluyas contraseñas, datos de pago ni información sensible.

Las consultas se conservan solo mientras sean necesarias para responder y dar seguimiento. Puedes pedir acceso o eliminación en cualquier momento escribiendo a fernelydev@gmail.com.

No se solicita información de tarjetas ni se procesa ningún pago mediante este formulario.
